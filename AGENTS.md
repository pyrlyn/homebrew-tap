## What this tap is

Homebrew tap for listepo tools. Two installable definitions:

| File | Kind | What it installs |
| --- | --- | --- |
| `Casks/ketch.rb` | cask `ketch` | Staged bootstrap of ketch. `stage_only`: the cask does not link a binary into the prefix; postflight runs `ketch self install` or `self upgrade` into `~/.ketch`. |
| `Formula/rtok.rb` | formula `rtok` | The `rtok` binary from a `pyrlyn/rtok` release tarball, into `bin`. |

The README documents `brew tap pyrlyn/tap`. This checkout's `origin` is
`git@github.com:listepo/homebrew-tap.git`. `plan.md` also names
`https://github.com/pyrlyn/homebrew-tap`.

`Casks/ketch.rb` says it is generated by `scripts/cask.sh` in the ketch repo and that the next ketch release overwrites the file. A `test do` block added here will disappear on that overwrite unless the generator emits it. `Formula/rtok.rb` lives in this repo; this checkout has no `.github/workflows` directory.

## Commands

```bash
brew tap pyrlyn/tap
brew install --cask ketch
brew install rtok
```

Smoke tests, not run from this change:

```bash
brew test rtok
brew test --cask ketch
```

Both `test do` blocks run the installed or staged binary with `--version`. They do not add download URLs.

## Do not

Do not invent bottle or release URLs. Change a `url` or `sha256` only when the matching upstream release artifact is already published.
